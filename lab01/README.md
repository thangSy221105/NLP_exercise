# LAB 01 — From Text Processing to Search

## Mục tiêu

- Tính và hiểu Count Vector, TF, IDF, TF-IDF và cosine similarity.
- Tự cài đặt pipeline TF-IDF tối giản.
- Khảo sát ảnh hưởng của preprocessing.
- Xây dựng và đánh giá document search trên corpus được cung cấp.

## Cấu trúc

- `calculations.md`: các bài tính tay trước khi kiểm chứng bằng code.
- `prediction.md`: prediction trước các experiment.
- `implementation.py`: implementation TF-IDF và unit tests.
- `experiments.ipynb`: thí nghiệm trên corpus.
- `results.csv`: kết quả retrieval/evaluation.
- `reflection.md`: reflection cuối lab.

## Cách làm đề xuất

1. Hoàn thành `calculations.md` bằng tay.
2. Ghi prediction vào `prediction.md`.
3. Hoàn thiện và chạy test trong `implementation.py`.
4. Chạy các experiment trong notebook.
5. Điền kết quả search, evaluation, error analysis và reflection.
